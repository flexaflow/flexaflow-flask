WordPress & Blogger

Bring a site here from WordPress or Blogger, or take your content to either of them. Users and passwords are never moved.

Import into FlexaFlow

WordPress: Tools → Export → All content, download the .xml.
Blogger: Settings → Manage blog → Back up content, download the .xml. A Google Takeout Blogger feed.atom file also works.

Imported HTML is cleaned (scripts and unsafe attributes removed). A post gets its first WordPress category; any further categories and all Blogger labels become tags. Comments are not imported. Everything is added under your account.

Export from FlexaFlow

Used to turn image and link addresses like /uploads/x.jpg into full web addresses, so they keep working after the move.

WordPress and Blogger fetch images from this site while importing, so it must be reachable from the internet at the address above. Page templates, extension records (such as faculty profiles) and other FlexaFlow-only features are not part of these formats; use Site → Export for a full backup.
